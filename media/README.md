# Личные медиа

Сюда помещаются подготовленные JPG, JPEG, PNG, MP4 и GIF для локального экземпляра бота.

Сами фотографии и видео исключены из репозитория. Для отправки финального котика нужен хотя бы один подходящий файл фотографии. Лимиты и фильтры указаны в `content_store.py` и `check_media.py`.
